# Dwarika Dheesh Print Packaging

A simple, premium React + Vite business website based only on the visual/product material supplied in the company's calendar.

## Requirements

- Node.js 20+ recommended
- npm

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Important

The project intentionally does not use external image URLs. The four solution images are crops from the supplied calendar image.

Before publishing, replace the placeholder phone/email in `src/App.jsx` with the company's verified contact details from the final approved business information.
